TripExpress

Sitio de ofertas de vuelos con registro, inicio de sesión y panel de administración.

Esto es una demo. El sitio necesita una API en Node con MySQL detrás, y una página estática no puede levantar eso. El código del navegador es el real, sin modificar; lo que está simulado son las respuestas del servidor. Los datos se reinician al cerrar la pestaña.
